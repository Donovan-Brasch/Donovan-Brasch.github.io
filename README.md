# Dono's site

Plain HTML, CSS and JavaScript. There's nothing to build or install.

## Change the polaroids

Put photos in `media/desk`, then edit the `polaroids` list in `content.js`. The first one sits on top.

## Turn on recommendations

Make a free form at formspree.io, then paste its link into `recsEndpoint` in `content.js`. Submissions arrive by email.

## Add links, classes and your picks

All of it is in `content.js`, along with videos and ceramics.

## Add travel pins and photos

Open `content.js` and find the Sciences Po section. Each place has its own photo list. Photos go in `media/abroad`.

## Add show media and hike details

Open `content.js` and find the top show and hike sections. Files go in `media/shows` and `media/hike`.

## Add videos and ceramics

Open `content.js`. Each section has an example to copy.

- **Videos:** upload to YouTube as unlisted, then paste the video ID. Or put a file under 100 MB in `media/music`.
- **Ceramics:** put photos in `media/ceramics`, then add a block with the photo's path and a title.


## Update Parkcast

Replace the files in the `parkcast` folder.
